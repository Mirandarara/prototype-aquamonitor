# AquaMonitor: pastas do protótipo

Esta pasta é a cópia independente do laboratório. O usuário também executa
`npm run dev` em `/home/mateus/Downloads/Aqua onitor/prototype-3d`, que pertence
à aplicação principal e contém a integração com o Dashboard.

Ao corrigir ou atualizar a maquete para o usuário, aplique as alterações também
à pasta integrada e valide a pasta servida pelo Vite. As duas pastas não se
sincronizam automaticamente. Preserve o adaptador `DashboardSimulationController`,
o modo incorporado e os controles Dashboard da cópia integrada. Não substitua
essa integração pela versão independente dos mesmos arquivos.
